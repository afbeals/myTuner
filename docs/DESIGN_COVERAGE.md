# Approved design implementation coverage

This inventory maps all **58 canonical frames** and the seven approved journeys to the implemented browser/native surfaces. Frames include state specimens and responsive variants; they do not each require a separate application route. Existing Silver Signal patterns also host the selected extensions. Source references below are relative to `web/src`, except the Kotlin native files under `android/app/src/main/java/tv/mytuner/app`.

The implementation has browser functional/axe/screenshot evidence and native JVM/build/lint/emulator evidence. The final native inventory uses30 reviewed synthetic PNG baselines across 28 surfaces, plus five dynamic screenshot/hierarchy specimens. It covers startup, connection failures/help, profile/PIN/guide states, playback and paused dialogs, reports, track menus and pairing removal. All 58 reference frames were visually reviewed, while pixel baselines compare the implementation on the documented API 34 ARM64 emulator. Actual display fidelity, spoken narration and physical-TV behavior remain [external acceptance](differed.md).

The [nested editor follow-up](UI_STATE_AUDIT.md#nested-browser-editor-follow-up) extends browser state/focus coverage for collections, subtitle locations, programming selection, next-episode lookup and exposure history. Its seven new narrow specimens and three refreshed dialog captures preserve the approved visual system; they do not add canonical Figma frames or certify the remaining native/exhaustive states.

## Owner-approved and contract-driven adaptations

- Full channel names and optional derived/supplied short names replace numbered fixtures. UUIDs remain internal identity.
- Pairing shows the API's ten hexadecimal characters, QR assistance and a device-review step before explicit browser approval.
- Channel/content editing uses separate accessible modals. Channel details save immediately; programming retains its own draft and boundary-safe publication.
- Sonarr/Radarr and read-only adjacent/mirrored NFO supply cached metadata; manual title/description choices are independent. Web parsing is excluded.
- Library details show available and retained unavailable files. Unavailable checkboxes are disabled; playback/scheduling selections still exclude them. Entirely undownloaded provider-only entries are not invented.
- Commercial cutoff, strict minimum remainder and optional episodes-per-turn extend the original boards using the same form patterns.
- Scope confirmation reports measured counts/duration/reuse and unknown size/time estimates; it does not present unsupported ETA promises. Backups are operator-triggered and their dashboard does not imply an automatic schedule.
- Playback context appears with controls; browsing, caption appearance and help preserve the current paused session. Optional I17 automatic overlay dismissal remains unselected.
