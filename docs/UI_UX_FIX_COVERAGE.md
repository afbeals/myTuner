## Boundaries preserved

- Source video, audio, subtitle and metadata files remain read-only. Tests use temporary synthetic content.
- Private channels and associated paths, counts and metadata remain owner/admin scoped. UI permission gates supplement server checks.
- Catalog browsing/search stays bounded and database-backed. The freshness batch does not probe source disks.
- The earlier wide-tree concern was withdrawn after actual virtualized scrolling; no fictional paging repair is claimed.
- Actual changed subtitle search roots/depth intentionally invalidate manual bindings; unchanged configuration/rescan retains them. The UI explains that distinction.
- Physical TV/Fire OS, target Unraid HDD/shared resources, Docker-engine acceptance on the equipped Windows host or CI, human accessibility and the owner-deferred emulator checks retain their existing [acceptance boundary](differed.md).
