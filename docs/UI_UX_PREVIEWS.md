# New UI/UX previews

These are captures of the implemented UI using disposable synthetic media. Preview PNGs are linked here for opening in Visual Studio Code. Automatic opening of test artifacts was stopped after the owner reported the interruption; test failure images and baseline updates must not auto-open. All 117 browser/accessibility/visual tests passed locally, including comparison against the reviewed regression baselines; these previews do not establish physical TV acceptance. The historical review screenshots in UI_UX_REVIEW.md illustrate earlier behavior.

## Current regression captures

The gallery below contains progress captures; some predate final spacing, action-label and search-control refinements. Current regression images live beside their `e2e/*.spec.ts` files in `*-snapshots/`. [The 93-image review index](/private/tmp/mytuner-ui-visual-review/index.md) provides contact sheets and original image paths; the final affected comparisons are recorded in [Verification](VERIFICATION.md). These local temporary links may disappear during cleanup. Nothing opens automatically.
