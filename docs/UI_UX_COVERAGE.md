## Decisions that apply to the entire trace

- [Accepted implementation decisions](UI_UX_IMPLEMENTATION.md) supersede the original “What needs agreement” proposals. My Network combines channel cards and catalog while retaining a direct Watch route. Collections/tray hold fixed exact references; whole-show/season/folder selections remain explicitly dynamic.
- New-channel drafts stay local through preview; final details/programming creation is atomic and retry-safe. Existing programming edits preserve the current program/break boundary and retained paused revisions.
- Source/profile/account/subscription settings use staged revision-guarded saves. Explicit scans and session revocation remain deliberate separate actions. Private channels remain owner/admin-only, including profile subscription dialogs and shared rooms; subscriptions grant no media access.
- Parent-folder selection includes the subtree; Select all applies to the currently loaded video page. Catalog browsing uses stored indexes; only explicit bounded setup browsing checks permitted filesystem directories. Media files, sidecars and original subtitle files remain read-only.
- Permanent profile/channel deletion is dependency-aware. Blocking retained references are explained; implementing the action does not authorize an implicit history purge, media deletion or forced migration.
- The exact reported Channels CSP violation and blanket collection-creation failure remain investigated/unreproduced. The exact moving generation animation also remains unconfirmed even though related count/polling/terminal-state defects were corrected. No CSP weakening or fabricated failure repair is claimed.
- Native source/build/JVM/lint coverage is separated from native runtime acceptance. No new emulator run, physical TV acceptance, host installation or deployment is implied by an implementation row.
